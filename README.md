# Florida Fort Lauderdale Mission — Mission Logistics Organizer

A web-based logistics organizer for the Florida Fort Lauderdale Mission.

## Current build
- Teaching-area board
- Mission-area map interface
- Area search and selection
- Add teaching areas
- Cars, Houses, Numbers, and Companionship tabs
- Add-record forms
- Responsive layout
- Local browser persistence for the area list

## Next build
- Supabase authentication and database
- Per-user ownership/edit permissions
- Shared real-time data for ~10 users
- PDF assignment upload, parsing, matching, and preview
- Drag-and-drop assignment of cars, houses, and phone numbers
- Persistent mission map asset and editable geographic boundaries

This first version is intentionally a frontend foundation so the hosted deployment can be tested before adding authentication and shared data.
